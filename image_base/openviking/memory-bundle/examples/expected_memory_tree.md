# Expected Company Memory Tree

```text
viking://user/<user_space>/memories/
├── profile.md
├── people/
│   └── <person_slug>.md
├── teams/
│   └── <team_slug>.md
├── projects/
│   └── <project_slug>.md
├── decisions/
│   └── YYYY-MM-DD-<decision_slug>.md
└── pages/
    ├── strategy/
    ├── product/
    ├── customers/
    ├── sales/
    ├── marketing/
    ├── operations/
    ├── engineering/
    ├── finance/
    ├── legal/
    ├── hiring/
    ├── glossary/
    ├── risks/
    ├── vendors/
    ├── metrics/
    └── raw_notes/
```

Resources are separate from extracted company memory:

```text
viking://resources/
├── docs/
├── repos/
├── exports/
└── threads/
```
